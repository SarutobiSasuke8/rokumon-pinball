# Gameplay Tuning

Put values that affect player feel in one named constants module and mirror important choices in `Templates/GAMEPLAY_CONSTANTS.md`.

Tune against a question, not a preference:

- Can a new player understand the objective within the first few seconds?
- Can an experienced player express mastery?
- Does failure teach rather than feel arbitrary?
- Does each input produce legible feedback?

Log major tuning changes in a session log or playtest report, including the pre-change behavior, changed constants, and observed effect. Use seeded debug runs for repeatable balance comparisons where randomness matters.
