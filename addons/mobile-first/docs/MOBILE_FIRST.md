# Mobile-First Addon

Use this addon when touch is a supported primary input, not merely a resize target.

- Set a portrait or landscape virtual resolution deliberately.
- Document touch actions, multi-touch combinations, and fallback controls in the control map.
- Test safe-area insets, notches, browser chrome changes, focus loss, orientation changes, and audio unlock on physical hardware.
- Keep persistent controls large, reachable, and out of the active playfield.
- Record actual device/browser coverage in every release-stage playtest report.
