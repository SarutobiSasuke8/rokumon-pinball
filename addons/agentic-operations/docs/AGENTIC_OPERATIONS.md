# Agentic Operations Addon

This is an opt-in operating layer for a game that has grown beyond a fast prototype. It supplements, rather than replaces, `AGENTS.md`, the persona council, and session logs.

## Surfaces

- `Agent State/` — current ownership, active work, blocked work, and handoff status.
- `Memory/` — concise durable lessons, gameplay decisions, and proven engine traps. Never copy private secrets or raw chat transcripts here.
- `QA/` — evidence-backed test plans, playtest reports, issue triage, and release gates.

Keep entries concise, dated, and attributable. Session logs remain the canonical historical record; these folders are live coordination surfaces.
